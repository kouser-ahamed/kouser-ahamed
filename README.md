[![Server](https://img.shields.io/badge/Server_Repo-181717?style=flat-square&logo=github)](https://github.com/kouser-ahamed/gymnest-server)

- 💳 Integrated **Stripe Checkout** for class bookings with duplicate prevention and full transaction history for admins
- 📊 Built three distinct dashboards (Member, Trainer, Admin) with **Recharts analytics**, class moderation, and community forum management
- 🔇 Developed **soft-block system** — blocked users can browse but cannot perform state-changing actions (enforced on both frontend and backend)
- 🔍 Implemented **MongoDB $regex search**, category filtering, and **server-side pagination** across all class and forum listing pages
